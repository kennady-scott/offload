# Offload

One place for all the little things teaching throws at you.

A teacher utility belt — not an LMS, not a curriculum platform, not another giant AI assistant.

## Pages

| File | What it is |
|---|---|
| `index.html` | Marketing home (logged out) |
| `app.html` | Signed-in home — the tool launcher |
| `css/tokens.css` | Shared color + type tokens. **Change colors here, not in a page.** |

Static HTML. No build step.

## Tools

**Right now:** Say This · Get Them Back · Bellringers *(start of class)* · Before the Bell *(end of class)* · Home Note · Sub Day
**Get something done:** Adapt It · Catch Me Up · Tiny Things · Plot Ruckus (opens plotruckus.com)

Each tool stays a free standalone site; the hub is what makes them all know the teacher's
classes, students, and routines.
